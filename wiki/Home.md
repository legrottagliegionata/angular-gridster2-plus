# angular-gridster2-plus

Angular dashboard grid with draggable, resizable and pushable widgets. It is a community-maintained fork of [angular-gridster2](https://github.com/tiberiuzuld/angular-gridster2) by [Tiberiu Zuld](https://github.com/tiberiuzuld): same API, active bug fixing and development.

- [Live demo](https://legrottagliegionata.github.io/angular-gridster2-plus)
- [Source code](https://github.com/legrottagliegionata/angular-gridster2-plus)
- Requires Angular 22

## Features

- Six grid types: fit to the container, scroll vertically or horizontally, fixed cell sizes
- Drag and resize with push, swap and compaction
- Empty cells: click, context menu, drop from outside, drag to create, hover preview
- Multiple layers, right-to-left layouts and a stacked mobile layout
- Follows window and container size changes
- Standalone components and signals; works with and without zone.js
